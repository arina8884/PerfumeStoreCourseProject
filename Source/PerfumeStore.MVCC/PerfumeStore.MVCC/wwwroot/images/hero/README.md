# Hero — главное изображение

Положите файл **`hero-main.webp`** в эту папку.

- Рекомендуемый размер: **1600×900 px** или **1920×800 px**
- Формат: **WEBP** (или JPG, тогда обновите расширение в `Views/Home/Index.cshtml`)
- Тематика: премиальный парфюмерный бутик, мягкий свет, нейтральные тона

Пока файла нет, отображается `hero-placeholder.svg`.

Подробности: `Database/IMAGE_MANIFEST.md` → раздел Hero.
